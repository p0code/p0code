# Use p0code as your default browser

On macOS, the desktop app can be your default web browser. Links you open from other apps then
open in p0code. When the thread on screen shows its browser panel, the link opens there as a new
tab. Otherwise it starts a new thread without a project, with the browser panel maximized on the
page, so you can ask an agent about it right away.

Choose **p0code** under **System Settings → Desktop & Dock → Default web browser**. To go back,
choose another browser there.

Choose **T3 Code** in **System Settings → Desktop & Dock → Default web browser** (switch back there anytime).

## How links open

A link that launches p0code waits until the app has connected to its environment, then opens.
