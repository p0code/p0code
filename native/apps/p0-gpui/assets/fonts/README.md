Inter 4 (SIL Open Font License 1.1, `LICENSE-Inter.txt`), the web app's interface font. Static
Regular/Medium/SemiBold/Bold instances of the `latin` and `latin-ext` subsets of
`@fontsource-variable/inter` 5.3.0, cut with fontTools `varLib.instancer` and merged, because GPUI
picks weights from separate faces.
